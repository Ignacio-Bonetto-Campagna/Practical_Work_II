# Practical Work II

## Description

For this Practical Work 2, I've chosen as a topic generative AI in video games, a topic that perfectly combines my passion for technology, mathematics, and gaming. In terms of website design, I decided to create a layout I personally enjoy seeing across many modern websites with a header at the top and a footer at the bottom. I intentionally placed social media links in the footer rather than just on the About page because this footer appears consistently across all pages, making my profiles accessible everywhere. For the visual aesthetic, I went with a design approach I find appealing: maintaining the same color for both header and footer sections while using a slightly different shade for the central content area. I specifically chose a subtle dark gray that isn't too contrasting, creating a cohesive visual experience. Throughout the site, I implemented a content presentation style I like alternating between images and text sections to create visual rhythm and better engagement. Additionally, drawing from my personal background having lived in Peru before moving to Spain, I included links to several classmates websites from my time there in the Net section. While some of these sites showcase more advanced techniques from their web development courses, I believe they're worth featuring as they represent meaningful connections from my academic journey across different countries. This design approach reflects both my technical interests and personal experiences in a clean, professional website structure.

## Problems during the development

The most challenging aspect was definitely working with dimensions and spacing throughout the website. I struggled constantly to achieve perfect alignment where elements wouldn't feel cramped or too spread out. Specifically in the header section, I faced significant difficulties combining the website logo with the navigation menu (Home, Net, Topic, etc.) they would often misalign, with the logo floating to one side while navigation links positioned themselves below or too far away. This spacing issue was less problematic in the footer since it mainly contained social media icons which were more forgiving to arrange. Another major challenge was organizing the CSS architecture. Initially, I thought I would need to create separate CSS files for each HTML page, but then realized many styles could be reused. I decided to consolidate everything into a single CSS file to optimize the project, but this approach actually created confusion as I sometimes applied styles to the wrong elements or mixed up selectors. Looking back as a beginner in HTML and CSS, I wonder if having separate CSS files might have been more intuitive for my first project. However, one thing that truly saved me throughout this process was using Git and GitHub, cause whenever I made significant mistakes or broke the layout completely, I could always revert to my last successful commit and recover from errors that would have otherwise cost me hours of frustration.
